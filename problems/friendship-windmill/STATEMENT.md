# Friendship theorem (Erdős–Rényi–Sós) — formalize-only

Authoritative pin: `catalog/problems/friendship-windmill/STATEMENT.md`.

**expected:** known-classical (1966). No novelty claim. Finite graphs only.

If `G` is a finite simple graph in which every two distinct vertices have
exactly one common neighbour, then some vertex is adjacent to all others.
