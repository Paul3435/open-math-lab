circulant matrix generated by a vector `v` is
the product, over roots of unity, of the
corresponding discrete Fourier evaluations
`∑_j v_j ω^{kj}`. Completely classical
(the circulant is a polynomial in the cycle
matrix; the Fourier matrix diagonalises it).

## Pinned convention (exact)

**v1 Level A is `det (circulant v)` on
`Fin n` over a commutative ring, for
`n = 0, 1, 2` (optional `n = 3` elementary
identity), not labelled circulant-det /
Fourier.** Count in `ℕ`.

Suggested pin:

```text
-- Level A (not labelled circulant-det / Fourier):
-- empty Fin 0; n = 1 evaluation; n = 2 a² − b²;
-- optional n = 3 a³+b³+c³−3abc.
-- Not labelled circulant-det.

theorem det_circulant_fin_zero
    {R : Type*} [CommRing R] (v : Fin 0 → R) :
    det (circulant v) = 1

theorem det_circulant_fin_one
    {R : Type*} [CommRing R] (v : Fin 1 → R) :
    det (circulant v) = v 0

theorem det_circulant_fin_two
    {R : Type*} [CommRing R] (v : Fin 2 → R) :
    det (circulant v) = v 0 ^ 2 - v 1 ^ 2

-- Level B namesake (ℂ / primitive root; residual OK)
theorem det_circulant {n : ℕ} {v : Fin n → ℂ}
    {ω : ℂ} (hω : IsPrimitiveRoot ω n) :
    det (circulant v) = ∏ k, ∑ j, v j * ω ^ (k.val * j.val)
```

## Proof sketch (classical)

Level A: `Fin 0` is `det_isEmpty` (`det = 1`).
`Fin 1`: `circulant v 0 0 = v (0-0) = v 0`,
and `det_fin_one`. `Fin 2`: subtraction on
`Fin 2` yields the symmetric `[[a,b],[b,a]]`
with `a = v 0`, `b = v 1`; `det_fin_two`
gives `a² − b²`. Optional `n = 3`: expand
Leibniz / row-reduction to
`a³ + b³ + c³ − 3abc`. **Not** labelled
circulant-det.

Level B: the cycle matrix `C = circulant
(Pi.single 1 1)` has `C^n = 1`; `circulant v`
is `∑_j v_j C^j`; eigenvalues of `C` are
primitive-root powers; det is the product of
eigenvalues. Equivalent: factor through the
Fourier / Vandermonde matrix. Cap two levels.
No pfaffian. No Kirchhoff. No `hadamard_det`.
No `schur_product`.
